# Vellum documentation

Vellum's documentation is available in two languages. Both language trees use the
same filenames and the same navigation shape so that a link can be understood
without first guessing which version exists.

## Choose a language

- [English documentation](en/index.md)
- [Documentación en español](es/index.md)

The [project README](../README.md) is the public introduction to Vellum. This
directory is the deeper layer: development setup, architecture, rendering notes,
and the public `.vellumstyle` reference.

## How to read the documentation

If you are new to the project, start with the project overview and then follow the
development guide. If you are trying to understand a particular implementation,
the integration architecture is the best map of how data moves through the
system. The rendering notes explain the decisions behind specific layers rather
than merely listing what the code contains.

The documentation describes the current codebase. When a document discusses a
future direction, it labels that direction explicitly.
